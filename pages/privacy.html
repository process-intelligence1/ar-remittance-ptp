Privacy Policy

AR Remittance & PTP Processing is a demonstration application for accounts-receivable remittance handling. This page explains what it does with data.

Who runs it

The demo is run by its owner, the operator of the mailbox processintelligence1@gmail.com. It is not a commercial service.

What data the application uses

  • E-mails in one demo mailbox. The application connects to that single Gmail mailbox (read, label and send permissions) to read incoming remittance and payment-promise e-mails, read their attachments, classify them and match them to open invoices.
  • Demo data. The invoices, customers and sample e-mails shown in the demo are synthetic. Do not send real customer or personal data to the demo mailbox.
  • Sign-in records. When you sign in to the demo, the application records the demo user you chose, the time and your network address in an audit log. The access code you type is never stored or logged.

How the data is used

Only to run the demo: to show the e-mails, extracted values, matches and the audit trail on screen. Outgoing e-mails created by the demo are sent only to the demo mailbox itself.

Sharing and retention

The data is not sold, shared with third parties or used for advertising or to train any model. It is kept in the demo's own database and file storage and can be deleted at any time by the owner. Gmail data is not transferred anywhere outside the demo's own systems.

Google user data

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions or deletion requests: processintelligence1@gmail.com.
